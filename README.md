# ClipForge AI

A free-first, Android-friendly browser clip editor.

## Included in this starter
- Load a video file stored on your device
- Preview and choose start/end timestamps
- Crop to vertical 9:16 or keep the original aspect ratio
- Add a simple burned-in caption
- Export a WebM clip locally in a supported browser

## Important limitations
This is the first working editor starter, not the complete AI clipping system yet.
- It does not automatically detect highlights.
- It does not download YouTube/Twitch videos. Use files you own or have permission to edit.
- Browser export currently creates WebM, not MP4.
- Long or high-resolution videos may exceed Android browser memory or processing limits. Try short clips first.

## Run it
Open `index.html` in a modern browser, or publish the repository with GitHub Pages:
1. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then Save.
5. Wait for GitHub Pages to publish, then open the URL shown there.

No API keys, account, or paid services are used by this starter.
